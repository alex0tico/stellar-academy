# 05 · Producto y MVP

Una buena tecnología no basta si no resuelve un problema real para personas concretas. Esta categoría aborda cómo pasar de una idea a un producto: identificar a quién se ayuda, qué necesidad se atiende y qué es lo mínimo necesario para probarlo.

Un MVP (producto mínimo viable) es la versión más simple de un producto que permite aprender de los usuarios con el menor esfuerzo posible. Trabajar así ayuda a validar supuestos antes de invertir tiempo y recursos.

Los conceptos se aplican a proyectos construidos sobre Stellar, pero son útiles para cualquier emprendimiento tecnológico.

## Qué aprenderás

- Cómo definir un problema y a quién afecta.
- Qué es un MVP y cómo delimitar su alcance.
- Cómo recoger retroalimentación y decidir los próximos pasos.
- Cómo comunicar una propuesta de forma clara.
