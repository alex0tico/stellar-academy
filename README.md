# Stellar Academy

Recurso educativo abierto de **Stellar Academy**, el programa de formación en blockchain de **Stellar Chile** en la Universidad de La Frontera (Temuco, Chile). Reúne material para aprender qué es blockchain, cómo funcionan las wallets, cómo se escriben contratos inteligentes en Soroban y cómo se construye un producto sobre la red Stellar.

El contenido está organizado por **categorías temáticas**, para que sirva a cualquier generación de estudiantes. Todo el material está en español.

> [!IMPORTANT]
> **Todo se practica en testnet y nunca se comparten llaves privadas.** La red de pruebas (testnet) usa fondos sin valor real. Jamás publiques, pegues en un chat ni subas a este repositorio una llave privada, una frase semilla o un archivo `.env`.

## ¿A quién está dirigido?

A **estudiantes principiantes**. No se necesita saber programar: cada categoría parte desde cero y explica los conceptos con lenguaje sencillo. Quien ya tenga experiencia puede saltar directamente a los temas que le interesen.
