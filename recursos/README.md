## Glosario

Definiciones breves y generales para quienes están comenzando.

| Término | Definición |
|---------|------------|
| **Blockchain** | Registro compartido de información, organizado en bloques enlazados, que mantienen muchos participantes sin depender de una entidad central. |
| **Wallet** | Herramienta que guarda y administra las llaves de una cuenta y permite firmar transacciones. |
| **Llave privada** | Secreto que da control sobre una cuenta. Nunca debe compartirse. |
| **Llave pública** | Identificador derivado de la llave privada que sí se puede compartir para recibir activos. |
| **Cuenta** | Identidad en la red, asociada a un par de llaves, que puede mantener activos y enviar transacciones. |
| **Testnet** | Red de pruebas, con fondos sin valor real, para practicar sin riesgo. |
| **Contrato inteligente** | Programa que se ejecuta en una blockchain y aplica reglas de forma automática. |
| **Soroban** | Plataforma de contratos inteligentes de la red Stellar. |
| **Rust** | Lenguaje de programación con el que se escriben los contratos de Soroban. |
| **WebAssembly** | Formato de código compilado y portable al que se traducen los contratos para ejecutarse en la red. |
| **Transacción** | Operación firmada que se envía a la red para registrar un cambio, por ejemplo un pago. |
| **Consenso** | Mecanismo mediante el cual los participantes de la red se ponen de acuerdo sobre qué se registra y en qué orden. |
| **Stellar Expert** | Explorador de la red Stellar que permite consultar cuentas, transacciones y contratos. |
| **Stellar Community Fund** | Programa de financiamiento para proyectos que se construyen sobre la red Stellar. |
